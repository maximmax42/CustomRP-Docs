# 🏠 मुख्य पृष्ठ

CustomRP docs में आपका स्वागत है!

ऐप डाउनलोड करने के लिए [Releases](https://github.com/maximmax42/Discord-CustomRP/releases) देखें। ऐप को सेट अप करने के निर्देशों के लिए [सेटअप](setting-up.md) पृष्ठ देखें।

अक्सर पूछे जाने वाले प्रश्नों के उत्तर और सामान्य समस्याओं के समाधान के लिए [FAQ](faq.md) पृष्ठ देखें।

क्या आप विकी में अपनी भाषा जोड़ना चाहते हैं? [GitHub repository](https://github.com/maximmax42/CustomRP-Docs) पर जाएँ और वहाँ दिए गए निर्देशों का पालन करें। यदि आप किसी मौजूदा भाषा का अनुवाद संपादित करना चाहते हैं, तो अनुवादित पृष्ठ के दाईं ओर स्थित मेनू में दिए गए "Edit on GitHub" लिंक का उपयोग करें।
